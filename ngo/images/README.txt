============================================================
 IMAGES FOLDER - Photo Placement Guide
============================================================

Place the following free-licence photos in this folder.
Suggested sources: Unsplash, Pexels, Pixabay (all free for
commercial and non-commercial use with no attribution required).

Each image should be a JPG, roughly 600-800px wide.

------------------------------------------------------------
FILE NAME            | WHERE IT IS USED       | WHAT TO PHOTOGRAPH
------------------------------------------------------------
hero.jpg             | index.php hero section  | A wide shot of volunteers working with a community (children, smiling faces, warm tone).
education.jpg        | index.php cause card    | Children in a classroom or studying with books.
health.jpg           | index.php cause card    | A healthcare camp: medical checkup, doctor with patients.
environment.jpg      | index.php cause card    | Volunteers planting trees or a green landscape.
food.jpg             | index.php cause card    | Food distribution: volunteers handing out meals or food packets.
about.jpg           | index.php about section  | A group of NGO volunteers posing together or working outdoors.
------------------------------------------------------------

NOTES:
- If an image is missing, the page still looks fine because
  each image container has a CSS background-colour fallback.
- File names must be EXACTLY as listed above (lowercase, .jpg).
- Keep file sizes under 200 KB each for fast loading.
